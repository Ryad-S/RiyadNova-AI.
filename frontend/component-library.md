# RiyadNova AI Component Library

## Overview

This document defines the reusable UI components used across the RiyadNova AI platform.

The component library ensures consistency, scalability, and a professional user experience across all application pages.

---

# Design Principles

Components should be:

- Simple.
- Reusable.
- Responsive.
- Accessible.
- Consistent with the brand identity.

---

# 1. Buttons

## Primary Button

Purpose:

Used for main actions.

Examples:

- Create Project.
- Start AI Analysis.
- Generate Report.

Properties:

- Clear action text.
- Modern shape.
- Smooth interaction.

---

## Secondary Button

Purpose:

Used for alternative actions.

Examples:

- Cancel.
- Learn More.
- View Details.

---

## AI Action Button

Purpose:

Special button for AI-powered features.

Examples:

- Ask AI.
- Analyze Idea.
- Generate Strategy.

---

# 2. Cards

## Project Card

Used to display business projects.

Contains:

- Project name.
- Description.
- Industry.
- Status.
- Progress.

---

## AI Feature Card

Used to display AI tools.

Contains:

- AI tool name.
- Description.
- Action button.

Examples:

- Market Research AI.
- Business Plan AI.
- Marketing AI.

---

## Report Card

Used for generated documents.

Contains:

- Report title.
- Date created.
- Report type.
- View button.

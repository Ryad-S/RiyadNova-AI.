# RiyadNova AI UI System

## Design Principles

- Simple
- Clear
- Modern
- User-focused

---

## Buttons

Primary Button:
Used for important actions.

Examples:
- Start Analysis
- Create Project

Secondary Button:
Used for alternative actions.

---

## Cards

Used for:

- AI tools
- Reports
- Projects
- Analytics

---

## Typography

Style:

- Modern
- Clean
- Easy to read

---

## Animations

Use:

- Smooth transitions
- Subtle futuristic effects
- AI-inspired movements

Avoid:

- Excessive animations
- Distracting effects
